# Villa Savana — sajt

Ceo sajt je jedan fajl: `index.html` (sve slike, stilovi i skripte su već unutra, ne treba ništa drugo).

## Kako da ga okačiš na GitHub Pages (besplatno hosting)

1. Idi na github.com i napravi novi repozitorijum (New repository). Nazovi ga npr. `villa-savana`. Ostavi ga **Public**.
2. U tom repu klikni **Add file → Upload files** i prevuci `index.html` (ovaj iz ovog paketa).
3. Commit (dugme "Commit changes").
4. Idi u **Settings → Pages** (levo u meniju repozitorijuma).
5. Pod "Build and deployment" izaberi **Deploy from a branch**, granu `main`, folder `/ (root)`, pa **Save**.
6. Za par minuta sajt će biti živ na adresi:
   `https://<tvoje-korisničko-ime>.github.io/villa-savana/`

## Sopstveni domen (opciono)

Ako kasnije kupiš domen (npr. villasavana.com), u istom Settings → Pages odeljku postoji polje **Custom domain** — upišeš domen tu, i kod svog registra domena dodaš CNAME zapis ka `<tvoje-korisničko-ime>.github.io`. Reci mi kad dođeš do toga, provešću te kroz to.
